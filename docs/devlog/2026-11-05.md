## 설계 메모 (사람·리뷰용)

- PC에는 Luau 실행기가 없어 spec은 Studio 명령줄에서만 돈다.
  항목 2 순수 함수(`laneStartTimes`)는 PC에서 Python 거울로 먼저 확인했다.
- `lane_order`(출발 순서·시각)는 서버가 `DirectorState`에 담아 보내서
  스폰·배너·성문 강조가 같은 순서를 쓴다(클라이언트 중복 계산 없음).
- 성문 묶음 스레드는 `pcall`로 감싸서 한 성문 스폰 실패가 웨이브를 멈추지 않는다.
  웨이브 정리 뒤 늦은 스폰이 새지 않게 `cancelled` 플래그를 둔다.
- 접힌 배너(`Mini`)와 큰 배너는 형제 프레임이라 한쪽만 보인다.
- 결과 첫 알림(저장 전)에는 `npc_memory`가 없어서 상태 줄이 비어 있다가,
  저장 뒤 두 번째 알림에서 문구가 붙는다.
